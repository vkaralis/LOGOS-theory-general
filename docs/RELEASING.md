# Publishing

The public repository is https://github.com/vkaralis/LOGOS-theory-general.
Software version 0.5.0 is declared in the package and citation file.

Before publishing changes, update `MANIFEST_SHA256.json` with the SHA-256 of
every distributed file except the manifest itself. Run the GitHub Actions
workflow and confirm its integrity, unit-test and full reproduction steps pass.

The associated manuscript has not yet been submitted. Do not add a journal
reference or DOI until one has been assigned.
