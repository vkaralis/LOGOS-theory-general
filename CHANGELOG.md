# Changelog

## [0.5.0] - 2026-10-12

- Added a packaged Python CLI for dimensionless LOGOS numerical benchmarks.
- Added fixed-amount finite optimization with 24 seeded timing starts.
- Added periodic factorial, local sensitivity and stress-cap reconstructions.
- Added recovery-gated whole-family bounds, parameter-box stress tests, imperfect information and a quadratic minimum-dose frontier.
- Added independent analytical and ODE verification, CSV tables and PNG/SVG plots.
- Added a deterministic synthetic PK cohort and data dictionary under MIT.
- Restricted supported Python to CPython 3.12 and pinned installation dependencies.
- Added clean-environment CI, reference comparisons and SHA-256 integrity checking.
- Added MIT license, GitHub topics and release instructions for v0.5.0.

The release covers the declared dimensionless examples. Clinical prediction and
fitted drug-specific applications are outside its reproduction scope.
